# HeatSmart AI — تشغيل المنصة

## المتطلبات
- Python 3.10 أو أحدث
- اتصال إنترنت أول مرة لتثبيت المكتبات
- لابتوب Windows / macOS / Linux

## التشغيل على اللابتوب
1. فكّي ضغط الملف.
2. افتحي Terminal أو Command Prompt داخل مجلد `HeatSmart_AI`.
3. أنشئي بيئة افتراضية (اختياري لكنه مستحسن):

### Windows
```bash
py -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

### macOS / Linux
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

4. يفتح المتصفح عادةً على `http://localhost:8501`.

## فتحها على الموبايل
- إذا اللابتوب والموبايل على نفس شبكة Wi-Fi، يمكن تشغيل Streamlit مع عنوان الشبكة المحلية:
```bash
streamlit run app.py --server.address 0.0.0.0
```
- افتحي عنوان IP المحلي للابتوب مع المنفذ `8501` من متصفح الموبايل. قد تحتاجين السماح للاتصال في جدار الحماية.
- للوصول من خارج الشبكة، انشري التطبيق على خدمة استضافة مناسبة بعد مراجعة إعدادات الخصوصية.

## مهم علمياً
القيمة المعروضة في صفحة «تحليل المعاملة» هي **قيمة توضيحية مصطنعة** لا تصلح كقيمة صلادة متوقعة فعلياً. استخدمي بيانات صلادة موثقة خاصة بدرجة الفولاذ نفسها قبل تقديم أي نموذج على أنه تنبؤ. صفحة CSV تسمح بتجربة تدريب نموذج أولي عند توفر بيانات كافية، لكنها لا تضمن التعميم أو الدقة.

## تنسيق CSV
الأعمدة المطلوبة:
- `austenitizing_temp_C`
- `holding_time_min`
- `tempering_temp_C`
- `tempering_time_h`
- `hardness_HRC`

يمكن إضافة `steel_grade` و`cooling_medium` للتوثيق، لكن نموذج النسخة الأولية يستخدم الأعمدة الرقمية الخمسة المطلوبة فقط (أربعة مدخلات وقيمة الصلادة الهدف).

## خطة تطوير مقترحة لعدة أسابيع
الأسبوع 1: تثبيت الفكرة، اختيار درجة فولاذ واحدة، جمع مراجع علمية.
الأسبوع 2: الحصول على بيانات موثوقة وتوثيق الوحدات والمصدر.
الأسبوع 3: تدريب النموذج ومقارنته بخط أساس بسيط وتقييم MAE/RMSE/R².
الأسبوع 4: اختبار حالات جديدة، تحسين الواجهة، إعداد التقرير وتجربة العرض.
